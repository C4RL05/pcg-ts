pcg-ts demos

Deterministic procedural content generation — graphs, fields, spawners, and the hierarchical runtime, rendered with three.js. Everything here re-cooks live from its seed.

Tool

Editor
Opens any graph in graphs/ and edits it live: palette, pin wiring with real graph validation, schema-driven params, a curated overview panel, JSON round-trip, and shareable links. Switch the cook path between the CPU and two GPU paths under a graph that does not change.

Demos

A single cook is a graph in graphs/, opened in the editor. What is left here needs a host: streaming worlds and a device-resident renderer.

Infinite world
Two-level hierarchical World streamed around a flying camera: unbounded landmarks above seamless 20-unit rock cells. A GPU toggle and a `derived specs` checkbox show combinator-authored fields reaching the device — and a panel explaining why nothing fuses into a run here.
 Galaxy
An infinite deterministic spiral galaxy: log-spiral density fields, streamed star cells with nebular dust, and click-to-visit planetary systems — every seed grows a different galaxy.
 GPU world
A streamed world drawn from instance matrices composed on the GPU and never read back — one shared device behind the field evaluator and a WebGPU renderer, with live readouts for retained device buffers and cell churn. Needs WebGPU.
 Racetrack
A closed circuit dressed by rule and drawn as the bounding boxes the rules actually measure: a host loop fits the kit to the lap, cooks, scores it against seventeen published metrics and corrects — with the plan laid over the driven view.
Run with npm run examples · seeds are deterministic: the same seed always rebuilds the same world.
